Who's actually watching the contingency reserve?

A cost-management methodology demo built around a synthetic capital-development program. Every number below is computed live in this page's own JavaScript — nothing is a static screenshot, and there's no build step, no server, no dependency to install.

The program is synthetic — no employer, client, or agency data appears anywhere in this repository. Three real facts are threaded through it, each cited where it appears: a real $208K variance root-cause trace, a real 100+ bid-package contingency-tracking pattern, and AACE International RP 57R-09 as the real, named method behind the Monte Carlo band. Everything else — the program name, dollar amounts, dates, vendor labels — is invented to make the methodology legible and is marked illustrative throughout; real figures are marked real.

Contingency Drawdown & AACE RP 57R-09 Monte Carlo Band real method

An elevated drawdown ratio early in a project — before field execution has consumed much float — is itself the early-warning signal, not just the running total. The P50/P80/P90 band below follows AACE International RP 57R-09 ("Integrated Cost and Schedule Risk Analysis Using Risk Drivers and Monte Carlo Simulation of a CPM Model") — a real, named industry practice, not an invented technique.
